# PARA와 Johnny.Decimal

> 2026-10-22 수업에서 들은 내용 정리

## 한 줄 요약
- **PARA**: 자료를 "**지금 나에게 어떤 의미인가**(행동)"로 나눈다.
- **Johnny.Decimal**: 모든 자료에 "**고유한 번호 주소**"를 붙인다.

## PARA
**티아고 포르테(Tiago Forte)**가 『세컨드 브레인(Building a Second Brain)』에서 소개한 방법이다.
자료를 **주제가 아니라 "얼마나 행동과 가까운가"**로 나눈다.

| 칸 | 뜻 | 내 예시 |
|---|---|---|
| **P**rojects | 마감이 있고 지금 진행 중인 일 | 포트폴리오 |
| **A**reas | 끝나는 날 없이 계속 챙기는 일 | 게임 플레이 이력, 공부 계획 |
| **R**esources | 나중에 참고할 관심 자료 | 회사 정보, 크론 잡 노트 |
| **A**rchives | 끝났거나 쉬고 있는 것 | (아직 비어 있음) |

애매한 자료는 **Inbox**에 두고 나중에 정리한다.

**핵심:** 자료는 **상황에 따라 칸을 옮겨 다닌다.**
예) 크론 잡 노트는 지금 Resources에 있다. 크론 잡을 쓰는 과제가 생기면 Projects로 옮기고, 과제가 끝나면 Archives로 보낸다.

## Johnny.Decimal
**조니 노블(Johnny Noble)**이 만든 방법이다.
도서관 책의 청구기호처럼 모든 자료에 **숫자 주소**를 붙인다.

```
10-19  학교                    ← 영역 (Area): 최대 10개
   11  게임 기획 수업           ← 카테고리 (Category): 영역마다 최대 10개
       11.01  1주차 과제        ← ID: 실제 자료
       11.02  기말 기획서
   12  유니티 프로그래밍
20-29  개인 게임 프로젝트
   21  zoojack
   22  로그타워
       22.01  맵 시스템
```

**핵심 규칙**
- **10개 제한**: 영역도 카테고리도 최대 10개까지다. 그래서 폴더가 끝없이 깊어지지 않는다.
- **번호로 찾기**: "22.01"만 기억하면 위치를 바로 알 수 있다.
- **자리 고정**: 한 번 정한 주소는 잘 바뀌지 않는다.

## 두 방법 비교
| | PARA | Johnny.Decimal |
|---|---|---|
| 나누는 기준 | **행동** (지금 하는 중? 끝났나?) | **주제** (무엇에 관한 것?) |
| 자료 위치 | 상황에 따라 **옮겨 다님** | 정해진 자리에 **고정** |
| 강점 | 지금 할 일에 집중하기 좋음 | 정확한 위치를 빠르게 찾기 좋음 |
| 약점 | 칸이 애매한 자료가 생김 (그래서 Inbox가 있음) | 처음에 번호 체계를 짜기 어려움 |

## 내 폴더에 적용한 모습
```
000_Inbox
100_Projects   ← 칸 이름은 PARA
200_Areas
300_Resources  ← 앞의 번호는 Johnny.Decimal식 아이디어
400_Archive
```

- **이름**(Projects, Areas…)은 PARA에서 왔다.
- **앞의 숫자**(100, 200…)는 Johnny.Decimal의 "번호로 순서와 위치를 고정한다"는 아이디어를 빌렸다. 덕분에 탐색기에서 늘 같은 순서로 보인다.
- 진짜 Johnny.Decimal이라면 `11.01`처럼 **자료 하나하나에도 번호**가 붙는다. 지금 구조는 맨 위 폴더에만 번호를 쓴 **혼합형**이다.
